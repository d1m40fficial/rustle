## 0.1.0 — 2026-11-07

Первый публичный релиз.

### Возможности

- WebView2-браузер с вкладками, сессией, закрытыми вкладками и восстановлением после падения.
- Адресная строка, история, закладки, поиск, автодополнение.
- Панель закладок, папки, импорт/экспорт Netscape HTML.
- Настройки: поисковик, тема, старт, HTTPS-first, очистка при выходе.
- Менеджер загрузок с прогрессом, отменой и открытием файла/папки.
- Приватное окно с временным профилем.
- Поиск по странице, масштаб, fullscreen, индикатор HTTPS.
- Favicon-кэш.
- Установщик per-user (без администратора) и portable ZIP.

### Требования

- Windows 10/11 x64.
- Microsoft Edge WebView2 Runtime.

### Ограничения

- Нет расширений Chrome (исследование в M6).
- Нет Lite-блокировки рекламы.
- Нет полного accessibility-аудита.
- Кастомных пунктов контекстного меню нет — используются нативные WebView2.
