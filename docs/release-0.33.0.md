# Rustle 0.33.0

- Аватар профиля — цветной кружок с инициалом в правом верхнем углу.
- Клик по аватару открывает выбор профиля.
- Цветные метки профилей в списке.
- Профили с PIN, выбором при старте и отдельными cookie.
- Если у профиля нет вкладок — открывается новая вкладка.
- Rutube-правила, авто-retry, верхняя панель, sticky save, кастомный скроллбар.
