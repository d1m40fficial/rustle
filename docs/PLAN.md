# План дальнейших улучшений Rustle

## 1. Профили (следующий приоритет)

- [ ] Каждому профилю — собственные вкладки, закреплённые плитки и сессия.
- [ ] Не открывать новое окно при переключении: переиспользовать текущее окно.
- [ ] Цвет аватара выбирать вручную, а не только автоматически по имени.
- [ ] Аватар показывать также в списке профилей и на экране выбора.
- [ ] PIN: хэширование, ограничение попыток, блокировка на минуту.
- [ ] Подтверждение PIN при переключении через аватар.
- [ ] Удаление профиля с подтверждением и очисткой его cookie.
- [ ] Импорт/экспорт профиля (без PIN).

## 2. Совместимость сайтов

- [ ] 306.yandex.ru: проверить цепочку редиректов и SameSite-cookie; fallback на mail.yandex.ru.
- [ ] Rutube: расширить правила для рекламных вставок в плеере и прероллов.
- [ ] Диагностика ошибок WebView2: показывать код ошибки и кнопку «Повторить».
- [ ] Таймаут загрузки с индикатором и отменой.
- [ ] User-Agent по сайтам (если требуется).

## 3. Вкладки и окно

- [ ] Верхняя панель вертикального режима: проверить на всех размерах.
- [ ] Настройка положения кнопок окна и аватара.
- [ ] Сохранение состояния групп/свёрнутости при переключении профиля.
- [ ] Дерево вкладок и drag-and-drop между профилями (позже).

## 4. Загрузки

- [ ] Очередь загрузок и ограничение одновременных.
- [ ] Докачка после перезапуска.
- [ ] Ограничение скорости.
- [ ] Уведомление о завершении.

## 5. Adblock

- [ ] Полный ABP-синтаксис: `$important`, `$badfilter`, `#@#`.
- [ ] Импорт списков из файла/URL.
- [ ] Whitelist на уровне домена с источником правила.
- [ ] Журнал с фильтром по вкладке.

## 6. UI/UX

- [ ] Настройки: поиск по настройкам, сброс отдельных секций.
- [ ] Кастомные горячие клавиши.
- [ ] Настройка панели инструментов drag-and-drop.
- [ ] Светлая тема без мигания при старте.
- [ ] Accessibility: фокус, ARIA, масштаб.

## 7. Тесты и стабильность

- [ ] IPC-тесты для профилей, загрузок и настроек.
- [ ] UI-смоук со скриншотами профилей/настроек.
- [ ] Crash reporter и восстановление после падения.
- [ ] Ночная сборка и проверка WebView2.
