# Rustle 0.7.0

**Дата:** 11 ноября 2026

- Постоянные частицы логотипа/надписи и настройки интенсивности.
- Ресайз окна: низкоуровневый mouse-hook, рекурсивный passthrough дочерних окон.
- Библиотека сессий с названиями/превью.
- UI контейнеров cookie и контейнер по умолчанию.
- Adblock: отдельный движок пользовательских правил (adblock-rust).
- Локализация RU/EN: основные страницы, меню, настройки и сайдбар.
- Скриншот только страницы, пауза загрузок, нечёткий поиск вкладок.
- Проверка обновлений и WebView2, тест пользовательских правил.
