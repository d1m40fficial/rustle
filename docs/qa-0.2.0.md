## Дальнейшие улучшения

1. **Восстановление вкладок после падения** — отдельный crash-recovery snapshot.
2. **Поиск по вкладкам** (Ctrl+Shift+A) и быстрое переключение.
3. **Профили/контейнеры** для изоляции cookie по группам.
4. **Экспорт/импорт настроек и групп**, а не только закладок.
5. **Горячие клавиши для групп**: свернуть все, перейти к следующей.
6. **Настройка цветов групп** и автоматическая группировка по домену.
7. **Менеджер сессий**: сохранённые наборы вкладок.
8. **Улучшение Adblock**: собственные правила, счётчик по сайту, быстрый whitelist из меню.
9. **PDF/скриншоты страницы** и интеграция с буфером обмена.
10. **Обновление WebView2** и проверка версии runtime в «О браузере».
11. **Локализация** интерфейса (RU/EN) через один словарь.
12. **Тесты**: unit для storage/adblock, smoke-тест окна и IPC.

## Известные ограничения

- Общая группа процессов WebView2 в Task Manager называется Microsoft Edge WebView2 — это ограничение runtime.
- Favicon новых произвольных сайтов может загружаться с задержкой; для приватного окна favicon-запросы отключены.
