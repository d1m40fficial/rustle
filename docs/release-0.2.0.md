# Rustle 0.2.0

**Дата:** 8 ноября 2026

Rustle 0.2.0 — крупное обновление интерфейса и вкладок.

## Что нового

- Группы вкладок в сайдбаре и горизонтальной полосе, сворачивание с выгрузкой WebView.
- Закреплённые вкладки: favicon-only в горизонтальном режиме и отдельный блок в сайдбаре.
- Вертикальная панель на всю высоту, крупный плюс рядом со сворачиванием.
- Полноценный Adblock на EasyList/EasyPrivacy с исключениями сайтов (hltv.org по умолчанию).
- Favicon-плитки на новой вкладке, редактирование и drag-and-drop.
- Модальное создание/переименование групп поверх сайта.
- Нативные контекстные меню вкладок без тёмной панели на весь экран.
- Масштаб главной страницы, тёмная тема #1F1F1F.
- Исправлены зависание спиннера при возврате из настроек, потеря фокуса после F9 и исчезновение сайдбара при добавлении вкладки в группу.
- Перетаскивание вкладок, перетаскивание окна за пустое место, центрированный топбар, единая высота шапки сайдбара.

## Установка

- **Установщик:** `Rustle-0.2.0-setup.exe` — per-user, без прав администратора.
- **Portable:** `Rustle-0.2.0-portable.zip` — распакуйте и запустите `rustle.exe`.
- Требуется Windows 10/11 x64 и WebView2 Runtime.
