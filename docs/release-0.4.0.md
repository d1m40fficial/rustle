# Rustle 0.4.0

**Дата:** 11 ноября 2026

- Постоянный эффект частиц логотипа/надписи Rustle с настройкой интенсивности и отключением.
- Исправление ресайза окна: дочерние WebView и вложенные окна пропускают края к родителю.
- Скриншот только области страницы, без панелей браузера.
- Нечёткий поиск вкладок с приоритетом совпадений.
- Пауза/продолжение загрузок.
- UI-настройки контейнеров cookie и контейнера по умолчанию.
- Экспорт/импорт настроек и групп, сессии, горячие клавиши групп, автогруппировка, пользовательские правила Adblock, PDF.
- Базовый RU/EN, исправления поисковика и переводчика.
