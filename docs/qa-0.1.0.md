## Установщик

- Тихая установка в отдельную папку: exit code 0.
- Файлы: rustle.exe, WebView2Loader.dll, README.md, LICENSE, unins000.exe.
- Запуск установленного rustle.exe: процесс жив.
- Тихое удаление: exit code 0, папка установки удалена.
- Проверка WebView2 Runtime в установщике реализована через реестр (HKCU/HKLM, WOW6432Node).

## Ручные сценарии (0.1.0)

- Новые вкладки, переключение, закрытие, восстановление сессии.
- История: запись, поиск, удаление, сохранение после рестарта.
- Закладки: звезда, панель, папки, импорт/экспорт HTML (реализованы; диалоги вручную не прогонялись).
- Загрузка 2 МБ: прогресс, «Готово», файл в Downloads, восстановление строки после рестарта.
- Приватное окно: временный профиль, session.json не меняется.
- Favicon GitHub: PNG в %LOCALAPPDATA%\Rustle\favicons.
- Светлая тема, настройки поисковика/HTTPS-first/clear-on-exit (UI реализован).
- Поиск по странице, масштаб, fullscreen, индикатор HTTPS.

## Не проверено

- Чистая Windows 11 VM без WebView2 Runtime: сообщение об отсутствии runtime не проверялось вживую.
- Permission-диалоги камеры/микрофона/гео на реальных сайтах.
- Импорт/экспорт закладок через нативные диалоги.
- Accessibility-аудит.
- Lite-блокировка рекламы (P2, не входит в 0.1.0).
