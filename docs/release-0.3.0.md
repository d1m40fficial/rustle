# Rustle 0.3.0

**Дата:** 11 ноября 2026

Крупное обновление после 0.2.0.

## Новое

- Crash recovery: автосохранение сессии и баннер восстановления после сбоя.
- Поиск/переключение вкладок: Ctrl+Shift+A.
- Контейнеры cookie: личный, рабочий, банк; отдельные профили WebView2.
- Экспорт/импорт настроек и групп (JSON).
- Сохранение/открытие сессий через файл.
- Горячие клавиши групп: Ctrl+Shift+G, Ctrl+Alt+Up/Down.
- Цвета групп и автогруппировка по домену.
- Свои правила Adblock и быстрый whitelist текущего сайта.
- PDF-экспорт страницы и скриншот окна.
- Настройка языка интерфейса RU/EN (базовая локализация).
- Unit-тесты Adblock и хранилища.
- Исправлен поисковик на отдельной странице новой вкладки.
- Переводчик открывается с главной страницы.

## Установка

- Установщик: Rustle-0.3.0-setup.exe.
- Portable: Rustle-0.3.0-portable.zip.
- Windows 10/11 x64 + WebView2 Runtime.

SHA256 — SHA256SUMS.txt.
