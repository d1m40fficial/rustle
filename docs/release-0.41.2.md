# Rustle 0.41.2 (локальный патч)

- Настройки: ссылки История/Закладки/О браузере перенесены в левую панель.
- Короткие разделители между всеми вкладками.
- Новые вкладки больше не фокусируют поиск и не ломают ширину вкладок.
- Кнопки быстрого меню выполняются нативно: тема, масштаб, язык, вкладки.
- Круглая кнопка текущего масштаба на странице.
- Вертикальные вкладки принудительно закрывают поиск вкладок.
- История справа: чёрточки, раскрывающиеся при наведении.
