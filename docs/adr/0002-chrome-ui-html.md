# ADR-0002: HTML-оболочка в отдельном WebView

**Статус:** принято
**Дата:** 2026-11-06

## Контекст

Оболочка браузера (вкладки, адресная строка, меню) должна быть быстрой,
доступной и удобной для ввода, включая IME. Дочерние WebView не позволяют
рисовать поверх себя средствами родительского окна (airspace).

## Решение

Chrome UI — отдельный WebView высотой 78 px, загружающий `rustle://localhost/chrome/`.
Контент — WebView вкладки ниже. Для выпадающих панелей chrome WebView временно
растягивается вниз и перекрывает контент; z-order проверен в M0.

## Последствия

- Полноценный ввод, IME, доступность и быстрый UI на HTML/CSS.
- Дополнительный WebView стоит ~60–100 МБ памяти.
- Нужен контроль z-order и аккуратная работа с фокусом.
- Контекстные меню — нативные, чтобы не зависеть от перекрытий.
- После M1 пересмотреть, если память не укладывается в бюджет: альтернатива —
  native/egui оболочка, но она проигрывает по вводу и доступности.
