# ADR-0001: движок 0.1 — WebView2 через wry

**Статус:** принято
**Дата:** 2026-11-06

## Контекст

Нужен браузер, который открывает современные сайты, быстро стартует и не тащит
в поставку целый Chromium. Долгосрочно рассматриваются расширения Chrome.

## Решение

Для 0.1 использовать системный WebView2 на Windows через wry и tao. Движок
скрыть за трейтом `BrowserEngine`; CEF-бэкенд для расширений исследовать после MVP.

## Последствия

- Установщик маленький, WebView2 уже есть в системе и обновляется Microsoft.
- Совместимость с сайтами на уровне Edge.
- Расширения Chrome на WebView2 невозможны; это отдельный этап M6 и отдельный
  бэкенд, а не обещание 0.1.
- GNU-сборка требует `WebView2Loader.dll` рядом с exe; DLL вендорена.
- Появляется зависимость от наличия WebView2 Runtime; установщик должен проверять.

## Альтернативы

- CEF: полный Chromium, расширения частично, но +150–250 МБ и медленный старт.
- Servo/Verso: полностью Rust, но совместимость с современными сайтами недостаточна.
- Electron: Node в рантайме, большой размер, не соответствует целям.
