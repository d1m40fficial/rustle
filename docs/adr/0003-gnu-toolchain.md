# ADR-0003: GNU-цепочка и WebView2Loader.dll

**Статус:** принято
**Дата:** 2026-11-06

## Контекст

На машине нет прав администратора и не установлен C++ workload Visual Studio.
Стандартная MSVC-сборка Rust недоступна. Пользователь предложил Scoop + GNU.

## Решение

Использовать `rustup-gnu` и `mingw` из Scoop. Проект остаётся совместимым
и с MSVC: код не содержит MSVC-специфичных зависимостей. В репозиторий добавлен
`assets/webview2/x64/WebView2Loader.dll`; build.rs копирует его в target рядом
с exe. CI собирает MSVC-вариант на windows-latest.

## Последствия

- Сборка работает без администратора.
- Для GNU-сборки обязателен WebView2Loader.dll; для MSVC он линкуется статически,
  но копирование не мешает.
- DLL — сторонний компонент Microsoft; добавлен NOTICE, перед релизом проверить
  условия распространения.
- GNU-сборка чувствительна к PATH (cargo и mingw). В README описана установка.
