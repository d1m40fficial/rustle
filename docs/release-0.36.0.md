# Rustle 0.36.0

- F9 при вертикальных вкладках закрывает поиск вкладок и не блюрит верхнюю панель.
- Верхняя панель вертикального режима остаётся над сайдбаром.
- Rutube: убраны слишком широкие правила, из-за которых страница могла зависать; оставлены точные advert-правила.
- Индикатор загрузки показывается только при retry/ошибке, а не поверх каждой страницы.
- Профили: переключение через event loop (без зависания), аватар.
- Sticky save, кастомный скроллбар, читаемый журнал блокировок.
