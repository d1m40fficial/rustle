# Rustle 0.39.0

- Новая компактная верхняя панель в стиле opencode: меню, домой, поиск, вкладки, кнопки окна в одной строке.
- Поиск как в Windows 11: свёрнутая кнопка «Поиск» с лупой, при фокусе расширяется, вкладки ужимаются.
- Переключение «Компактная/Классическая» в настройках.
- История запросов справа на главной: карточки, открытие в новой вкладке.
- Тройной клик по вкладке закрывает её.
