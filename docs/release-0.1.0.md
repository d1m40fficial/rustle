# Rustle 0.1.0

Первый публичный релиз минималистичного браузера на Rust и WebView2.

## Установка

**Установщик** — `Rustle-0.1.0-setup.exe`, per-user, без прав администратора.  
**Portable** — распакуйте `Rustle-0.1.0-portable.zip` и запустите `rustle.exe`.

Требуется Windows 10/11 x64 и Microsoft Edge WebView2 Runtime.

## Что внутри

- Вкладки, сессия, восстановление после падения.
- История и закладки в SQLite, папки, панель закладок, импорт/экспорт HTML.
- Адресная строка с автодополнением; поисковик на выбор.
- История, закладки, настройки, загрузки и «О браузере» — внутренние страницы.
- Менеджер загрузок: прогресс, отмена, открытие файла/папки.
- Приватное окно (`Ctrl+Shift+N`) с временным профилем.
- Поиск по странице (`Ctrl+F`), масштаб (`Ctrl+±`, `Ctrl+0`), fullscreen (`F11`).
- Favicon-кэш, светлая/тёмная тема, HTTPS-first и индикатор безопасности.
- Очистка cookies/кэша и опция очистки при выходе.

## Известные ограничения

- Нет поддержки расширений Chrome.
- Нет Lite-блокировки рекламы.
- Нет полного accessibility-аудита.
- Кастомных пунктов контекстного меню нет.
- Приватное окно — отдельный процесс; профиль удаляется после закрытия, но при аварийном завершении временная папка может остаться до следующего запуска.

SHA256 файлов — в `SHA256SUMS.txt`.
