# Rustle 0.5.0

**Дата:** 11 ноября 2026

- Постоянный эффект частиц с настройками интенсивности/отключения.
- Ресайз всех краёв и углов (дочерние WebView пропускают edge-hit).
- Скриншот только области страницы.
- Нечёткий поиск вкладок Ctrl+Shift+A.
- Пауза/продолжение загрузок.
- UI контейнеров cookie и контейнер по умолчанию.
- Библиотека сессий с названиями и превью в настройках.
- Расширенные пользовательские правила Adblock, быстрый whitelist.
- Проверка обновлений и версия WebView2 на странице «О браузере».
- Базовый RU/EN, фиксы поисковика и переводчика.
